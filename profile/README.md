<h1 align="center">A nota fiscal do aluguel, mais simples.</h1>

A **Locanota** está construindo uma plataforma de emissão de NFS-e para locação de imóveis, pensada para locadores, contabilidades, imobiliárias e administradoras de condomínio.

Nossa proposta é reunir contratos e a rotina mensal de emissão em um só lugar, para facilitar o trabalho de quem administra aluguéis.

🚧 **Estamos em desenvolvimento.** Conheça a proposta e cadastre-se no site para acompanhar as novidades e receber o aviso de lançamento.
